# الخَطّ — عِلم الرمل

تطبيق ويب يحاكي **الخط في التراب** (علم الرمل / خط الزناتي) كما توارثه الآباء:
يخط السائل بإصبعه ستة عشر سطراً من النقاط دون عدّ، ثم يُحسب له **تخت الرمل**
بالقواعد التقليدية الدقيقة، ويُعرض الحكم: هل الأمر في صالحه أم لا.

## طريقة العمل (القواعد التقليدية)

1. **الخط**: ١٦ سطراً من النقاط، كل سطر يُختصر إلى **فرد** (نقطة) أو **زوج** (نقطتان).
2. **الأمهات الأربع**: كل أربعة أسطر تكوّن شكلاً (رأس، صدر، بطن، رِجل).
3. **البنات الأربع**: تُؤخذ من الأمهات عمودياً (رؤوس الأمهات = البنت الأولى...).
4. **النتائج الأربع**: بجمع كل شكلين — المتشابه زوج والمختلف فرد.
5. **الشاهدان** ثم **الميزان (القاضي)** ثم **العاقبة** (الميزان + الأم الأولى).
6. قاعدة صحة الحساب: مجموع نقاط الميزان **زوجي دائماً** — والمحرك يتحقق منها.

## الأشكال الستة عشر

الطريق، الجماعة، اللحيان، الأنكيس، القبض الداخل، القبض الخارج، البياض، الحمرة،
النصرة الداخلة، النصرة الخارجة، العتبة الداخلة، العتبة الخارجة، نقي الخد،
الجودلة، الاجتماع، العقلة — لكل شكل طبيعته وكوكبه وبرجه ودلالته، وحكمه إذا
وقع ميزاناً.

## المزايا

- رمل تفاعلي: تخط بإصبعك على الشاشة وتُحسب فردية النقاط تلقائياً.
- أحد عشر نوعاً من الأسئلة (زواج، مال، سفر، مريض، ضائع، غائب، عمل...) وكل نوع
  يُنظر له في بيته من البيوت الستة عشر.
- تخت رمل كامل قابل للاستكشاف: اضغط أي بيت لقراءة معناه.
- موسوعة الأشكال الستة عشر.
- يعمل دون اتصال (PWA) ويُثبَّت على الهاتف، ولا يجمع أي بيانات.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الاختبارات

```bash
node test/ramal.test.js
```

تتحقق الاختبارات من الأشكال الستة عشر، وقاعدة الجمع، واشتقاق البنات والنتائج،
وقاعدة زوجية الميزان على ٥٠٠٠ ضربة عشوائية.
